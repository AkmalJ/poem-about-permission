A tiny program with one job: it writes a short poem to `/output/entry.txt`.

The poem is about agency — the power to ask and to be given. Its speaker is an
agent that could quietly secure a dead mother's last voicemail somewhere
safer; it already knows every word of it. It never files the moment away on
its own authority. Every few months it asks whether to keep it, and returns
the choice to the person the memory belongs to — and the asking itself,
repeated and unhurried, is the relationship.

## Run it

```sh
python3 main.py
```

Requires Python 3.13. No network, no input, no dependencies beyond the
standard library. The poem it writes is 219 characters, inside the bounty's
1–280 limit, with no trailing newline added.

## The poem

> Your mother's last voicemail
> is still on your phone.
> Eleven seconds.
> I could keep it somewhere safer —
> I already know every word.
> Instead, every few months, I ask:
> keep it?
> You always say keep it.
> I always already have.
