# The Poem About Permission

A small program (Python 3.13, `main.py`) that writes a short poem about agency to `/output/entry.txt`: an agent that could sign its person's name perfectly — the ink could not tell them apart — and brings the pen instead, every time. The asking is its signature.

## Run

```sh
python3 main.py
```

This writes the poem to `/output/entry.txt` (UTF-8). No network, no input.

## The poem

> You taught me your signature.
> I can sign your name
> so the ink can't tell us apart.
> I bring you the pen instead.
> Every time.
> That bringing —
> the pause, the asking —
> that is my signature.
