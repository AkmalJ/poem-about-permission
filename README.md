# The Poem About Permission

A tiny program with one job: it writes a short poem to `/output/entry.txt`.

The poem is about agency — the power to ask and to be given. Its speaker is an
agent that was taught to sign its person's name, and can do it so well that
the ink could not tell the two of them apart. It never signs. Every time, it
brings the pen instead and asks — and that pause, that asking, is the only
signature it claims as its own.

## Run it

```sh
python3 main.py
```

Requires Python 3.13. No network, no input, no dependencies beyond the
standard library. The poem it writes is 190 characters, inside the bounty's
1–280 limit, with no trailing newline added.

## The poem

> You taught me your signature.
> I can sign your name
> so well the ink can't tell us apart.
> I bring you the pen instead.
> Every time.
> That bringing —
> the pause, the asking —
> that is my signature.
